# Сайт ООО «Севкавгипроводхоз»

Исходники статического сайта `sevkavgiprovodhoz.ru`. Собирается скриптом на
Python в чистые статические файлы — без фреймворков, без jQuery, без сборщиков.

```
D:\web_skgvh\
├── build.py              сборщик и проверка
├── src\                  исходники (всё, что правится руками)
│   ├── data\site.json      контент: услуги, контакты, реквизиты, тексты
│   ├── partials\           общие блоки: шапка, подвал, спрайт, стили, скрипты
│   └── templates\          страницы + layout.html
├── tools\
│   ├── images.py           подготовка изображений (Pillow)
│   └── tests\              стенды проверки вёрстки
├── assets-src\           исходные фото и логотипы (не выкладываются)
└── public\               ГОТОВЫЙ САЙТ — выкладывается на хостинг
```

Резервная копия исходной вёрстки: `D:\web_skgvh_backup_20261015`

---

## Быстрый старт

```powershell
python build.py            # собрать сайт в public\
python build.py --check    # проверить ссылки, мета-теги, CSS-токены
python build.py --serve    # локальный просмотр http://127.0.0.1:8765/
python tools\images.py     # перегенерировать изображения
```

Требуется Python 3.11+ и Pillow: `python -m pip install pillow`

## Как править

**Тексты, услуги, контакты, реквизиты** → `src\data\site.json`
Ничего не дублируется: шапка, подвал и счётчик подключаются ко всем
страницам из `src\partials\`, правится в одном месте.

**Разметка страницы** → `src\templates\<страница>.html`
Общие блоки `{% include "header" %}`, `{% block main %}` и т.д.

**Стили** → `src\partials\theme.css` (он же копируется в `public\css\theme.css`)

**Иконки** → `src\partials\icons.svg`, подключение: `{{ icon('phone') }}`

Синтаксис шаблонов:

| Что | Как |
|---|---|
| Значение | `{{ site.name }}` |
| Экранирование | `{{ text \| escape }}` |
| Условие | `{% if page.topbar %} … {% else %} … {% endif %}` |
| Цикл | `{% for s in services %} … {% endfor %}` |
| Вложенный цикл | `{% for item in s.items %}` |
| Метаданные цикла | `loop.index0`, `loop.first`, `loop.last` |
| Общий блок | `{% include "footer" %}` |
| Картинка | `{{ picture('img/g-mashuk-01', 'описание') }}` |

После любой правки: `python build.py`, затем `python build.py --check`.

## Проверка вёрстки

```powershell
python build.py --dev
python build.py --serve
```

Затем открыть:

- `http://127.0.0.1:8765/__testall.html?w=390` — все страницы сразу,
  показывает, есть ли горизонтальное переполнение на заданной ширине
- `http://127.0.0.1:8765/__testframe.html?w=390&h=1600&page=index.html` —
  отдельная страница в узкой рамке

Стенды копируются в `public/` только с флагом `--dev`; обычная сборка их
удаляет, поэтому на сервер они не попадут.

Полезные ширины: 360, 390, 768, 1024, 1440.

## Технические решения

**Подача.** Тёмная техническая тема: глубокий тёмно-синий фон, светящаяся
«чертежная» сетка, стеклянные панели, акценты cyan/blue. Крупная типографика
Manrope и моноширинные технические подписи. Анимации отмечают структуру
и статус, но не мешают чтению — всё гасится при `prefers-reduced-motion`.

**Фреймворков нет.** Вместо Bootstrap 3.4.1 (EOL с 2019) — своя дизайн-система
на CSS Grid и custom properties. Вместо jQuery 1.12.4 (CVE-2020-11022/11023) —
обычный JS. Экономия: около 350 КБ трафика и меньше точек отказа.

**Шрифт — Manrope**, самохостинг, 6 подмножеств по `unicode-range`.
Русскому посетителю браузер скачает только кириллический файл (~14 КБ),
остальные не загрузятся.

**Анимации** (все — CSS + JS, без библиотек):

- *Фон*: canvas-поле частиц по направленному потоку (`js/bgfield.js`) —
  частицы соединяются линиями, курсор слегка их отталкивает
- *Схема*: анимированная SVG-схема водоснабжения — по каналам «течёт» вода,
  узлы пульсируют (`src\partials\schematic.svg`)
- *Стекло*: анимированная градиентная рамка, блик следует за курсором
- *Появление*: блоков при прокрутке (IntersectionObserver), заголовков — по словам
- Hero: каскад при загрузке + параллакс фото
- Бегущая строка направлений, счётчики, волны, дыхание фонового свечения,
  подсветка иконок, блик по кнопкам, lightbox галереи, прогресс прокрутки

### Про «жидкое стекло»

Градиентная рамка рисуется через `padding: 1px` + `mask` + `mask-composite:
exclude` — иначе получится сплошная заливка, а не кольцо. Угол вращается
через `@property --glass-angle` (без него `conic-gradient` не анимируется).
Там, где `@property` не поддерживается, рамка просто статична — стекло
остаётся рабочим.

**Ограничения по ресурсам:** число частиц считается от площади экрана,
DPR ограничен двойкой, анимация встаёт на паузу в скрытой вкладке, при
`prefers-reduced-motion` поле рисуется один раз статично.

**Счётчик Яндекс.Метрики** грузится только после согласия пользователя
(баннер внизу), без `webvisor` при отказе. Это снимает риск по 152-ФЗ/GDPR.

**Доступность.** `prefers-reduced-motion` полностью отключает движение.
Бесконечные анимации перечислены в правиле явно: общее сокращение длительности
переводит их в один кадр, но элементы с задержкой продолжают числиться
активными в `getAnimations()`. Есть режим повышенной контрастности, вся
навигация с клавиатуры, фокус-кольцо, `skip-link`, у картинок осмысленный `alt`.

### Вес первой загрузки главной (gzip)

| Устройство | Было | Стало |
|---|---|---|
| Телефон | ~325 КБ | **56 КБ** |
| Планшет | ~325 КБ | **70 КБ** |
| Десктоп | ~325 КБ | 196 КБ |

Скрипты: `app.js` 5 КБ + `bgfield.js` 2.4 КБ в gzip.
На десктопе тяжелее: фоновая фотография 1920px — 125 КБ.

## Что делать при выкладке

1. Привязать домен `sevkavgiprovodhoz.ru` к хостингу в панели reg.ru —
   сейчас он отдаёт парковочную страницу, сайт не работает.
2. Выпустить SSL-сертификат на домен и `www`. Текущий — служебный
   `*.hosting.reg.ru` с чужим именем, плюс HSTS на год: браузер
   заблокирует доступ, даже если пользователь захочет продолжить.
3. Залить содержимое `public\` в корень сайта.
4. Создать `/files/` и загрузить документы из списка выше.
5. Настроить 404: отдавать `/404.html` с кодом 404, а не 200.
6. При смене файлов выставить заголовки кэширования:
   `Cache-Control: max-age=31536000` для `/css/`, `/js/`, `/img/`,
   и `no-cache` для `.html`.
