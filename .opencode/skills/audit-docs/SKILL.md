# Audit Docs

В конце каждой сессии обнови оба документа. Только после зелёного регресса.

## AUDIT.md

1. В чеклист задач добавь новые строки: `| N | Задача | ✅ | дата (что сделано) |`
2. В журнал изменений добавь секцию `### <дата> — <тема сессии>`:
   - что сделано, в каких файлах
   - баги, найденные по ходу (с причиной)
   - итог регресса (числа PASS/FAIL обоих тестов)
   - что НЕ сделано и почему (ждёт решения пользователя)
3. Не коммитить секреты. Даты — реальные.

## DEV_GUIDE.md

Добавляй только выстраданное — то, что стоило времени:

- Раздел 3 («Где искать по типу бага»): новая строка `симптом → файлы:строки`
- Раздел 5 («Ловушки»): каждый баг, на который наступил дважды или который тесты не ловят
- Формат ловушки: что сломалось → причина → как чинить
