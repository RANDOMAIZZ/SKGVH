Политика обработки персональных данных

Как {{ site.shortLegalName }} обращается с данными пользователей сайта {{ site.url | truncate:30 }}.

1. Общие положения

Настоящая Политика описывает порядок обработки персональных данных пользователей сайта {{ site.url }} (далее — Сайт) и разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Оператором персональных данных является {{ site.shortLegalName }}, ИНН {{ requisites.inn }}, ОГРН {{ requisites.ogrn }}.

2. Какие данные мы собираем

Сайт не содержит регистрации, авторизации и формы ввода персональных данных. Мы не создаём профили пользователей и не запрашиваем документы онлайн.

  • {{ icon('check-circle') }}Данные, которые вы сами указываете в письме, отправленном на {{ contacts.emails[0] | truncate:24 }} или {{ contacts.emails[1] | truncate:24 }}
  • {{ icon('check-circle') }}Обезличенные технические сведения: тип устройства, браузер, источник перехода, просмотренные страницы

3. Файлы cookie

Сайт использует локальное хранилище браузера (localStorage), чтобы запомнить ваш выбор относительно счётчика посещений. Эта запись не содержит идентификаторов и третьих лиц.

Счётчик Яндекс.Метрики загружается только после вашего согласия. Пока вы не выбрали вариант, аналитические скрипты не загружаются вовсе. Согласие можно изменить, очистив данные сайта в настройках браузера.

4. Цели обработки

  • {{ icon('check-circle') }}обработка обращений, направленных на {{ contacts.emails[0] | truncate:24 }}
  • {{ icon('check-circle') }}подготовка ответа на запрос о составе и стоимости работ
  • {{ icon('check-circle') }}анализ популярности разделов Сайта в обезличенном виде

5. Передача третьим лицам

Оператор не продаёт и не передаёт персональные данные третьим лицам, за исключением случаев, прямо предусмотренных законодательством Российской Федерации.

6. Сроки хранения

Данные, полученные по электронной почте, хранятся не дольше, чем необходимо для целей обработки обращения, если иной срок не установлен договором или требованиями законодательства.

7. Ваши права

Вы вправе запросить сведения об обработке ваших персональных данных, потребовать их уточнения, блокирования или уничтожения, а также отозвать согласие на обработку.

Запрос направляется на {{ contacts.emails[0] }} или по адресу: {{ contacts.legalAddress }}. Ответ предоставляется в срок, установленный законом.

8. Изменения Политики

Оператор вправе изменять настоящую Политику. Актуальная редакция всегда размещена по адресу {{ site.url }}/privacy.html.
